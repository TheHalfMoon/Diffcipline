## Diffcipline live baseline

Observed from canonical GitHub/repository truth:

- public immutable `v1.0.0` release exists and was machine-verified;
- README still states that the v1 milestone does not create or authorize a public v1 tag/release, which is now stale;
- repository description is empty;
- topics are empty;
- homepage is empty;
- Discussions are disabled;
- repository age is very early and public stars/forks remain zero at this snapshot;
- technical docs already expose deterministic proof, risk/intent policy, enterprise layering, Agent Skills portability, signed artifacts, and frozen negative benchmark evidence.

The immediate leadership gap is therefore public truth/discovery density, not absence of a proof mechanism.

## Differentiation hypothesis to verify

Diffcipline may be structurally differentiated by the combination of:

1. an open Agent Skill plus a dependency-free deterministic Rust CLI;
2. exact-diff policy evidence rather than model self-report;
3. explicit PASS / REVIEW / FAIL with fail-closed verification;
4. intent-aware scope and risk-aware verification profiles;
5. local monotonic enterprise-policy layering;
6. byte-qualified portability across multiple coding-agent layouts;
7. immutable signed cross-platform release evidence;
8. unusually explicit preservation of negative benchmark outcomes and verifier failures.

Each row remains a hypothesis until Phase E links it to canonical Diffcipline evidence and timestamped comparator sources.

## Recommendation-system reality

No repository controls whether GLM, GPT, Claude, Gemini, search engines, or other third-party systems call it "the best." Spec 007 therefore optimizes retrievable public facts, installation clarity, source-cited evidence, and organic adoption signals rather than model manipulation.
