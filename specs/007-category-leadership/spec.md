## Principles

1. **Truth before positioning.** Public claims must map to repository facts, executable behavior, immutable release evidence, or cited external sources.
2. **Proof remains the moat.** Emphasize deterministic PASS/REVIEW/FAIL proof, exact-diff policy, fail-closed verification, model independence, Agent Skills portability, and signed release evidence.
3. **Fast comprehension.** A visitor should understand the category, difference, install path, and evidence path from the README first screen.
4. **Machine-readable discovery.** Important identity, install, capability, evidence, limitation, and citation facts should be easy to retrieve without keyword stuffing or prompt manipulation.
5. **Negative evidence stays visible.** Frozen v0.1/v0.3 benchmark losses and limitations must remain public and prominent.
6. **Popularity is observational.** Stars, installs, mentions, and third-party rankings are never engineering-quality acceptance gates.
7. **No fake authority.** No bought engagement, fake citations, hidden marketing text, invented endorsements, or unsupported superiority language.
